TamaPoke KO v3.61.2 - PMDCatalog Stability Update

기준: v3.61.1 FULL PMDCollab Catalog + GitHub Pages
대상: Waveshare ESP32-S3-Touch-AMOLED-1.75 (466x466)

주요 안정화
1. PMDCollab 행동 스프라이트 패킹 시 투명 여백을 action-wide union bbox 기준으로 잘라냄.
   - 움직임/도트 표현은 유지.
   - TPK2 파일 크기, SD 로드 시 픽셀 스캔, 매 프레임 렌더 작업량 감소.
2. 펌웨어 렌더러가 PmdAct의 visL/visR/visT/base 범위만 순회하도록 변경.
   - 큰 투명 캔버스를 가진 포켓몬의 CPU 낭비 감소.
3. PmdAct 전체 애니메이션 시간을 load 시 1회 계산해 totalMs로 캐시.
4. 프레임 스케줄러 안정화.
   - 미니게임/배틀: 약 90ms 목표.
   - PMD가 무거운 홈/도감 상세: 약 120ms 목표.
   - 기타: 약 125ms 목표.
   - 렌더 오버런 뒤 20~36ms recovery guard를 둬 연속 full-screen QSPI flush에 의한 검은 깜빡임/tearing을 완화.
   - 최근 터치 입력은 다음 프레임을 즉시 당겨 UI 반응성 유지.
5. 기존 v3.61.1의 2.8MiB TPK2 size-safe 규칙 유지.
6. GitHub Pages 자동 배포 유지. Netlify 불필요.

검증
- tools/pack_pmd_catalog.py Python 문법 검사 통과.
- synthetic 64x64 2-frame PMD fixture를 15x16 visible crop TPK2로 패킹하고 2-frame 움직임 유지 확인.
- FW_VERSION / scheduler / visible-bound renderer / cached totalMs 정적 검사 통과.
- GitHub Actions에서 실제 ESP32-S3 arduino-cli compile + Pages deploy를 최종 통과 기준으로 사용.

주의
- 실제 기기에서 10~20분 soak test를 권장. Serial의 `RENDER slow=...` 로그가 반복되는 특정 포켓몬이 있으면 그 dex ID와 화면을 기록할 것.
- PMDCollab 외부 카탈로그는 업데이트될 수 있으므로 새 Actions 빌드마다 pmd_catalog_report.txt / pmd_sprite_report.txt를 확인할 것.
