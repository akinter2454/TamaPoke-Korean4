TamaPoke KO v3.63.6 인터페이스 가독성 개선 패치

- 메뉴 글자를 기본 3배율로 확대하고, 긴 문구는 자동으로 2배율로 축소합니다.
- 홈 화면 상태 문구를 기본 3배율로 확대하고 화면 폭에 맞춰 자동 축소합니다.
- 포켓몬 이름/레벨 헤더가 긴 경우 화면 폭에 맞춰 자동 축소합니다.
- 훈련 안내, 박스 이름/레벨, 상태 카드 보조 문구, 기술 안내를 확대했습니다.
- 가방의 아이템 이름·효과와 기술머신 설명을 확대하고 행 너비에 맞춰 자동 축소합니다.
- 타입 칩과 작은 고정 배지는 공간이 좁으므로 기존 크기를 유지합니다.
- 공격·방어·스피드 훈련 완료 화면의 일반/희귀 보상 문구를 2배율로 확대했습니다.
- 긴 보상 이름은 결과 패널 폭을 넘지 않도록 자동으로 축소됩니다.
- 능력치 화면의 일반 IV 값은 회색 대신 고대비 검정으로 표시합니다.
- IV 표시는 3배율을 우선 사용하며 공간이 부족한 번역에서는 2배율로 자동 조정됩니다.

기존 저장 데이터, 게임 규칙, 도감 ID, SD/WebSerial 프로토콜은 변경하지 않았습니다.
