설치/업데이트
1. 이 ZIP의 내용을 기존 GitHub 저장소 루트에 덮어씁니다.
2. 기존 tools/catalog_lock.json이 저장소에 있다면 반드시 보존합니다.
3. Actions -> "TamaPoke v3.62.4 PMDCatalog - Regional Evolutions + Reliable SD Sync + Mega36 GitHub Pages" -> Run workflow.
4. build/deploy 성공 후 Pages 설치기에서 펌웨어를 업데이트합니다.

v3.62.4 핵심
- 알로라/가라르/히스이 지역폼 진화 연결 전수 회귀검사.
- 히스이 침바루 -> 장침바루, 히스이 포푸니 -> 포푸니크를 regional form ID에서 연결.
- 가라르 직구리/나옹/코산호/파오리/마임맨/데스마스의 새 진화 종도 regional form ID로 연결.
- Basculin White를 Hisui-origin으로 분류하여 Basculegion 진화 경로를 제공.
- Paldea Wooper -> Clodsire 동일 오류 재발 방지.
- regional-evolution-report.txt를 Pages에 게시.

기존 기능
- 5분 절전/물리 버튼 wake, SDINFO proto=2 reliable WebSerial, 전체 스프라이트 동기화, 리소스 검수, Mega36 Lv.70, IV 랜덤/훈련 보상, 진화 Lv.100 상한 유지.
