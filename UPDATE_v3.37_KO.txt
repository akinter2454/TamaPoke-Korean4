TamaPoke 한국어판 v3.37 업데이트

[UI 버튼음 재구현]
- v3.36까지의 UI 버튼음은 게임 효과음과 같은 GbSynth 음성 채널을 사용했습니다.
- 실제 기기에서 소리 테스트는 정상인데 일반 UI 버튼음이 들리지 않는 사례가 계속되어, v3.37에서는 UI 버튼음을 게임 신스에서 완전히 분리했습니다.
- 일반 UI 탭은 이제 설정의 "소리 테스트"가 사용하는 것과 같은 직접 I2S -> ES8311 -> PA -> 스피커 경로로 재생됩니다.
- 한 번의 정상 UI 탭마다 짧은 2음 버튼음 요청을 1회 생성합니다.
- 버튼음 재생 전 남아 있는 GbSynth 음성 꼬리를 정리하고, 게임 음악이 없는 화면에서는 재생 후 PA를 LOW로 리셋합니다. 다음 탭은 PA를 다시 켜면서 완전히 새 재생으로 시작합니다.
- 빠른 연속 터치에서 요청이 쉽게 유실되지 않도록 오디오 큐를 16개에서 24개로 늘렸습니다.

[업데이트 시 버튼음 설정 복구]
- v3.33~v3.36을 거치며 NVS에 버튼음 OFF 또는 0 음량이 남아 있을 가능성을 제거하기 위해 v3.37 최초 부팅에서 한 번만 버튼음 ON / 음량 8로 복구합니다.
- 이후에는 설정 화면에서 사용자가 선택한 버튼음 ON/OFF 및 음량을 그대로 저장하고 존중합니다.
