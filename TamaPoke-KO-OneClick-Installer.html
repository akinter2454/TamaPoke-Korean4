🧹 완전 초기화

이 브라우저는 설치를 지원하지 않습니다. HTTPS에서 열어 주세요.

v3.37 설치 방식: 세이브 유지는 앱 바이너리만 기록하고 ESP Web Tools의 데이터 삭제 선택을 사용자에게 표시합니다. 유지하려면 설치창에서 데이터 삭제를 선택하지 마세요. 완전 초기화는 전체 플래시를 지운 뒤 4개 펌웨어 영역을 다시 설치합니다.

필요한 4개 파일명 / 주소
  • bootloader.bin → 0x0000
  • partitions.bin → 0x8000
  • boot_app0.bin → 0xE000
  • app.bin → 0x10000

2microSD 스프라이트 넣기

펌웨어 설치 후 보드를 정상 부팅하고 microSD 카드를 꽂으세요. 기기 연결을 누른 뒤 원하는 지역을 선택하면 스프라이트를 USB Serial로 전송합니다.

지역 하나가 약 20–42MB라 몇 분 이상 걸릴 수 있습니다. 전송 중에는 탭과 USB 연결을 유지하세요.

연결 안 됨

메가진화 36종만 추가는 Mega36의 일반/색이 다른 스프라이트만 전송합니다. 현재 추가 스프라이트 전체는 810번 이후 신규 세대·공식 폼·Mega36을 현재 카탈로그 ID대로 모두 다시 기록합니다.

microSD의 스프라이트를 현재 카탈로그와 한 번에 맞춥니다.

관동→성도→호연→신오→하나→칼로스→알로라 기본팩을 차례로 전송한 뒤, 가라르·히스이·팔데아·지역폼·추가폼·Mega36 전체를 현재 ID로 덮어씁니다. 플레이 세이브는 건드리지 않습니다. 예전 catalog_lock으로 받은 1200번대 스프라이트가 섞였을 때 이 기능을 한 번 실행하는 것을 권장합니다.

현재 빌드가 사용하는 내부 ID → 포켓몬 이름 → National Dex → PMDCollab 원본 경로를 직접 확인할 수 있습니다. 810번 이후 항목은 실제 TPK3 생성에 사용한 원본에서 뽑은 미리보기 PNG를 표시합니다.

자동 전송이 막히면 을 사용할 수 있습니다.
