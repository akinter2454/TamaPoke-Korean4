TamaPoke KO v3.62.1 - Mega36 microSD delta transfer fix

문제
- v3.62.0에서 기존 v3.61.x 사용자가 Mega36만 추가하려고도 '현재 추가 스프라이트 전체'를 눌러야 했음.
- 이 경로는 이미 SD에 있는 1200+ 기존 폼까지 다시 전송하며 p1200.bin 같은 오래된 대형/민감 파일에서 불필요하게 실패할 수 있었음.

수정
- GitHub Actions가 승인 Mega36만 묶은 sprites-extra-mega36-*.pak을 별도로 생성.
- sprite-manifest.json schema 2에 groups.mega36 및 counts.mega36_files=72 추가.
- 설치기에 '메가진화 36종만 추가' 버튼 추가. 기존 v3.61.x SD 사용자는 이 버튼만 1회 실행하면 됨.
- 첫 설치용 '현재 추가 스프라이트 전체'에는 기존처럼 신규 세대/폼 + Mega36 전체가 포함됨.
- 전송 로그에 개별 파일 크기를 표시하고, 실패 시 나머지 수백 파일을 계속 시도하지 않고 즉시 중단하여 원인 파악을 쉽게 함.

펌웨어 게임 로직/세이브 구조/메가 Lv.70 진화 규칙은 v3.62.0과 동일.
